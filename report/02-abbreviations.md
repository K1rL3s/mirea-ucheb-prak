# ПЕРЕЧЕНЬ СОКРАЩЕНИЙ И ОБОЗНАЧЕНИЙ

| Сокращение | Расшифровка                                                                 |
|------------|-----------------------------------------------------------------------------|
| ДТП        | дорожно-транспортное происшествие                                           |
| ПДД        | Правила дорожного движения                                                  |
| СУБД       | система управления базами данных                                            |
| B2B        | Business to Business, модель «бизнес для бизнеса»                           |
| B2C        | Business to Consumer, модель «бизнес для потребителя»                       |
| BPMN       | Business Process Model and Notation, нотация моделирования бизнес-процессов |
| ER         | Entity-Relationship, модель «сущность-связь»                                |
| FK         | Foreign Key, внешний ключ                                                   |
| IDE        | Integrated Development Environment, интегрированная среда разработки        |
| JSON       | JavaScript Object Notation, текстовый формат обмена данными                 |
| LTS        | Long-Term Support, долгосрочная поддержка                                   |
| NoSQL      | Not only SQL, нереляционные системы хранения данных                         |
| P2P        | Peer to Peer, модель «равный равному»                                       |
| PK         | Primary Key, первичный ключ                                                 |
| SQL        | Structured Query Language, язык структурированных запросов                  |
| UML        | Unified Modeling Language, унифицированный язык моделирования               |
| VCS        | Version Control System, система контроля версий                             |
| XML        | eXtensible Markup Language, расширяемый язык разметки                       |
