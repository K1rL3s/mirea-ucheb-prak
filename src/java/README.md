# Объектно-ориентированная реализация завершения аренды

Программа определяет зону завершения аренды и рассчитывает стоимость поминутной поездки. Затем сверяет снимки с обязательными ракурсами и определяет статус автомобиля

## Сборка и запуск

Из каталога репозитория:

```sh
cd src/java
java -version
mvn -version
mvn clean package
java -jar target/carsharing.jar
```

Требуются JDK 25 и Maven 3.9.9. В выводе `mvn -version` должна быть указана Java 25. При первом запуске Maven загрузит библиотеку Jackson для чтения JSON и плагины сборки

После распаковки архива КТ3 команды те же. Программа ищет `data.json` в текущем каталоге. Путь к другому файлу в формате КТ2 можно передать при запуске

```sh
java -jar target/carsharing.jar /путь/к/data.json
```

Сверка с процедурной версией из каталога `src/java` в полном репозитории:

```sh
python3 ../main.py data.json > target/python.txt
java -jar target/carsharing.jar data.json > target/java.txt
diff -u target/python.txt target/java.txt
```

Пустой вывод `diff` означает, что результаты совпали

## Пример входных данных

В `data.json` аренда 2 закончилась вне разрешённых зон с остатком топлива 6 %. При сдаче машины не сделаны снимки с ракурсами «Сзади» и «Салон»

```json
{"rental_id": 2, "booking_id": 2, "started_at": "2026-10-20T12:20:00", "finished_at": "2026-10-20T13:02:30", "finish_lat": 55.6512, "finish_lon": 37.4120, "fuel_end": 6, "zone_id": null, "cost": null}
```

## Правила обработки данных

Программа проверяет зоны в порядке их записи в JSON и считает границу частью зоны. Длительность каждого сегмента отдельно округляется вверх до полной минуты. Как и в КТ2, ставки и суммы записываются строками с двумя десятичными знаками. Для сегментов используется местное время в формате ISO 8601

Если фотоосмотра при сдаче нет, программа считает, что не хватает всех обязательных ракурсов. Статус «на обслуживании» присваивается при отсутствии или неполном фотоосмотре либо при остатке топлива менее 10 %. Программа выводит результат в консоль и сохраняет исходный JSON без изменений
