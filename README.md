## Что нужно сделать за практику

1. Описать основной бизнес-процесс - аренду автомобиля в каршеринге (КТ1, 06.10)
2. Построить схемы бизнес-процесса в нотации (КТ2, 03.11)
3. Определить автоматизируемые операции (КТ2)
4. Разработать алгоритмы для этих операций: схемы и оценка сложности (КТ2)
5. Реализовать алгоритмы процедурно на Python (КТ2) и объектно-ориентированно на Java (КТ3, 24.11)
6. Спроектировать базу данных, развернуть её в PostgreSQL и заполнить тестовыми данными (логическая модель - КТ2, физическая - КТ4, 15.12)
7. Протестировать решение и оценить качество кода (КТ4)
8. По мелочам: описать роли команды по Scrum, изучить рынок труда и подобрать курсы, магистратуру и аспирантуру для повышения квалификации разработчика по теме практики: каршеринг, IoT и телематика, автомобильные системы (КТ3)
9. Финальный отчёт: аннотация, заключение и глоссарий на английском, устная защита на английском (21.12)
