# ВВЕДЕНИЕ

Каршеринг позволяет арендовать автомобиль на короткое время через мобильное приложение. Работа сервиса требует согласования бронирований, данных поездки, фотоосмотров, расчёта стоимости и состояния автопарка.

В работе рассматривается учебная модель компании-оператора с ручным ведением части внутренних операций. Автоматизация проверки комплектности фотоосмотров, определения зоны завершения, расчёта стоимости и смены статусов автомобиля направлена на сокращение задержек и ошибок учёта в этой модели.

Тема практики - «Каршеринг легковых автомобилей». Целью практики является разработка модели и программного прототипа для автоматизации процесса аренды автомобиля в каршеринге. Прототип представляет собой консольные приложения на языках Python и Java, работающие с реляционной базой данных.

Для достижения цели необходимо решить следующие задачи:

- освоить среду разработки и систему контроля версий, провести анализ предметной области, описать основной бизнес-процесс, сформировать список источников и выполнить перевод фрагмента иностранного источника;
- построить модель основного бизнес-процесса в нотации BPMN (Business Process Model and Notation), выявить автоматизируемые операции, разработать логическую модель данных и алгоритмы автоматизируемых операций, оценить их вычислительную сложность и реализовать их на языке Python средствами процедурного программирования;
- спроектировать классы и реализовать решение на языке Java средствами объектно-ориентированного программирования, сопоставить две реализации, описать состав и роли команды разработки, оценить требования рынка труда и образовательные программы;
- реализовать физическую модель данных в системе управления базами данных (СУБД) PostgreSQL, составить тестовые сценарии, выполнить тестирование и описать проектное решение;
- подготовить аннотацию и глоссарий основных терминов на английском языке и представить результаты работы на английском языке.

Объектом исследования является процесс аренды автомобиля в компании-операторе каршеринга.

Предметом исследования являются модели данных, алгоритмы и программные реализации на языках Python и Java, автоматизирующие операции процесса аренды автомобиля.
