# ВВЕДЕНИЕ

Каршеринг, то есть поминутная аренда автомобиля, за десять лет стал заметной частью транспортной системы российских мегаполисов. В 2022 году Москва стала мировым лидером по размеру автопарка каршеринга, превысившему 30 тыс. единиц, а число пользователей сервиса превысило миллион человек [1]. По итогам 2024 года в столице совершено 53 млн поездок, а один автомобиль арендуют в среднем 5-6 раз в сутки [2].

Клиент каршеринга проходит весь путь от бронирования до оплаты в мобильном приложении, однако часть операций по-прежнему держится на ручном труде сотрудников и на добросовестности пользователя. Состояние автомобиля фиксируется фотоотчётом, который клиент делает сам, а повреждения обнаруживаются и оспариваются уже после поездки, причём в одном из описанных случаев доказательством послужили фотографии, на которых нельзя было разобрать даже номер автомобиля [3]. Поэтому автоматизация процесса аренды автомобиля остаётся актуальной задачей.

Целью практики является разработка модели и программного прототипа для автоматизации процесса аренды автомобиля в каршеринге. Прототип представляет собой консольные приложения на языках Python и Java, работающие с реляционной базой данных.

Для достижения цели необходимо решить следующие задачи:

- освоить среду разработки и систему контроля версий, провести анализ предметной области, описать основной бизнес-процесс, сформировать список источников и выполнить перевод фрагмента иностранного источника;
- построить модель основного бизнес-процесса в нотации, выявить автоматизируемые операции и разработать логическую модель данных;
- разработать алгоритмы автоматизируемых операций, оценить их вычислительную сложность и реализовать их на языке Python средствами процедурного программирования;
- спроектировать классы и реализовать решение на языке Java средствами объектно-ориентированного программирования, сопоставить две реализации, описать состав и роли команды разработки, оценить требования рынка труда и образовательные программы;
- реализовать физическую модель данных в СУБД PostgreSQL, составить тестовые сценарии, выполнить тестирование и описать проектное решение.

Объектом исследования является процесс аренды автомобиля в компании-операторе каршеринга.

Предметом исследования являются модели данных, алгоритмы и программные реализации на языках Python и Java, автоматизирующие операции процесса аренды автомобиля.
